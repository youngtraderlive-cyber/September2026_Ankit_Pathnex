Ansibl - Configure firwell with iptable
- name: Configure firewell with iptables
  hosts: all
  become: yes
    tasks: 
      - name: Set default plicies to drop all traffic
        command: iptable -P INPUT DROP
      - name: Allow shh and HTTP taffic
        command: Iptables - A INPUT -p tcp --dropt 22 -j ACCEPT
        command: iptables -A INPUT -p tcp --dport 80 -j ACCEPT
      - name: Save iptables configuration
        command: service iptables save
